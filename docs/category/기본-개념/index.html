기본 개념

LangGraph의 핵심 구성 요소인 State, Node, Edge, Graph에 대해 알아봅니다.

📄️ State (상태 관리)

State는 LangGraph의 핵심 개념으로, 그래프의 모든 노드가 공유하는 데이터 구조입니다. 각 노드는 State를 입력받아 처리하고, 수정된 State를 반환합니다.

📄️ Node (노드)

Node는 그래프에서 실제 작업을 수행하는 단위입니다. 각 노드는 State를 입력받아 처리하고, 업데이트된 State를 반환합니다.

📄️ Edge (엣지)

Edge는 노드 간의 연결과 실행 흐름을 정의합니다. 단순 연결부터 조건부 분기까지 다양한 패턴을 지원합니다.

📄️ Graph (그래프)

Graph는 Node와 Edge를 조합하여 전체 워크플로우를 구성하는 컨테이너입니다. 그래프 빌드, 컴파일, 실행의 전체 과정을 다룹니다.
